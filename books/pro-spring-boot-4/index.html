What this book helps you build

Spring Boot makes it easier to get started. This book helps you go further: from the framework’s internals to the decisions involved in testing, securing, observing, deploying, and evolving production applications.

Felipe and I bring experience from enterprise software, developer advocacy, cloud platforms, distributed data, and the Spring community to examples designed for working developers.

Who it’s for

Experienced Spring developers
Deepen your understanding of Spring Boot 4 and the systems surrounding production applications.
Java teams modernizing applications
Navigate security, data access, observability, native compilation, cloud patterns, and framework upgrades.
Technical leads and architects
Build shared context around current Spring practices and the tradeoffs behind them.
